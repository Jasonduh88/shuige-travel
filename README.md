# 水哥趴趴走｜獨立旅遊網站

這是可直接部署到 GitHub Pages 的靜態網站初版。

## 建議部署步驟
1. 在 GitHub 建立新的 **Public** repository，例如 `shuige-travel`（不要修改現有的 `static-website-sop`）。
2. 將 `index.html` 上傳到新 repository 的根目錄，Commit changes。
3. 進入 Settings → Pages，Source 選 Deploy from a branch，Branch 選 main、/(root)，Save。
4. 等 GitHub Pages 顯示已部署後，再使用它提供的實際網址；預期形式為 `https://jasonduh88.github.io/shuige-travel/`，但必須部署後驗證才能加入 Linktree。
5. 驗證手機與電腦版、所有連結、官方活動資料後再正式宣傳。

備註：頁面為首版，沒有聲稱已親自造訪所有燈區；活動與交通請依最新官方公告確認。
